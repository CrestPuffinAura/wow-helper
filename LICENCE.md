## 🧩 About

**World of Warcraft Helper** is a comprehensive utility for World of Warcraft, featuring an overlay, menu, and various helper functions to enhance your gameplay experience.

Based on popular addons like **WeakAuras**, **ElvUI**, and **Deadly Boss Mods**.

## ✨ Features

### 🎮 Core Features
- Overlay — display customizable information on screen
- Menu — easy access to all helper functions
- Config — save and load personalized settings
- Utility — additional tools for convenience

### 🎨 Visual Enhancements
- HUD Customization — adjust layout and colors
- Map Enhancements — improved map readability
- Loot Tracker — keep track of your loot

### 🏋️ Gameplay Helpers
- Radar — nearby points of interest
- Cooldown Tracker — monitor ability cooldowns
- Auto-Config — optimize settings for your class
